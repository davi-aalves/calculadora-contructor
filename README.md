# 📃 Calculadora com Constructor Functions

Este projeto é uma calculadora básica desenvolvida em **JavaScript**, utilizando **Funções Construtoras (Constructor Functions)** para estruturar a lógica do aplicativo.

## ✨ Tecnologias Utilizadas
- JavaScript
- HTML (interface básica)
- CSS (estilização básica)

## 🌐 Funcionalidades
- Operações matemáticas básicas: **soma, subtração, multiplicação e divisão**
- Utilização de **funções construtoras** para instanciar objetos calculadora
- Métodos para realizar cálculos

## 🛠️ Como Usar
1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/calculadora-constructor.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd calculadora-constructor
   ```
3. Abra o arquivo `index.html` em seu navegador para utilizar a calculadora com interface.
